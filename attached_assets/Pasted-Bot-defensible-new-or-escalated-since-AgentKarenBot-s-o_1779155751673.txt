Bot-defensible (new or escalated since AgentKarenBot's original scope):

Fake CAPTCHA bots inside trading groups — biggest new vector. Looks like a legit verification step ("tap here to verify"), actually harvests session tokens, injects clipboard malware, or exfiltrates private keys from Telegram-bot wallets. The Unihax0r $200k drain on May 11 came through this. Bot defence: flag any new member or bot posting CAPTCHA-style prompts with external links within X seconds of joining.
Fake "Official Support" channel impersonation — SEAL researchers found hundreds of these in late 2025. Aged or stolen channels refilled with botted "members," admins mimic the real project. End game is a permit signature trap that drains via ERC-20 approve() / transferFrom(). Bot defence: fuzzy-match admin usernames + channel handles against a known-good list, alert on near-misses (zero-width chars, swapped letters, similar avatars).
Permit signature / wallet-connect bait — instead of a seed-phrase ask, the link asks for a "small fee" or "verification signature" that's actually unlimited spend approval. MetaMask drainer detection can be bypassed. Bot defence: regex/URL-blacklist on known drainer domains (Inferno Drainer infra), block any message with eth_signTypedData_v4 style links, flag Fragment lookalikes.
Fragment username-sale scam — scammer offers to buy your @username, sends a Fragment-lookalike deep link inside Telegram's in-app browser, victim signs an approve(). Bot defence: detect "buy your username" DM solicitations + Fragment URL spoofs.
TON Mini-App drains — fake Notcoin / Hamster Kombat / tap-to-earn clones connecting TON wallets to malicious contracts. Bot defence: whitelist of legitimate Mini-App URLs, block all others posted in chat.
AI-cloned admin / founder impersonators — Ripple flagged 50+ fake Schwartz/Garlinghouse accounts on Telegram in Q1 alone. Often DMs members who post in the main chat. Bot defence: cross-reference any DM-initiation pattern with admin display names; warn members on join that admins never DM first.
Pump-and-dump signal groups — PumpCell alone did $800k in October 2025. Coordinated buys, sniper bots dump on retail. Solidus Labs identified 2,079+ events via NLP. Bot defence: keyword classifier ("buy signal," "100x guaranteed," contract addresses posted with countdown timers).
Seed phrase / private key requests — still working in 2026. Bot defence: hard regex block on 12/24-word mnemonic patterns and 64-char hex strings, auto-ban poster.
Mass-add to scam groups — Telegram is banning 80–140k channels/day at 4–5x pre-crackdown rate, but scammers re-add faster than removal. Bot defence: invite-link rate-limiter, auto-leave detection for known scam channel IDs.
Pig butchering DM bait — new member joins, lurks, then DMs active posters with a "trading mentor" pitch. AI now lets one operator run hundreds of these simultaneously (Chainalysis: 4.5× more revenue than non-AI scams, avg $3.2M per op). Bot defence: warn-on-join, encourage members to report unsolicited DMs, track which accounts trigger multiple DM-complaints.
Fake giveaway / airdrop bots — "send 1 ETH receive 2 ETH" still working with deepfake video proof attached. Bot defence: block messages containing giveaway-pattern + wallet address + countdown urgency.
