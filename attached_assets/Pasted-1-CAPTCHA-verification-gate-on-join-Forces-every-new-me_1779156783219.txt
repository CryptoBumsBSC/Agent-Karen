1. CAPTCHA / verification gate on join. Forces every new member to solve a button-tap or short challenge before they can speak. Kills roughly 90% of automated spam bots before they ever post — single highest-leverage feature. Without this, every other rule is firefighting.
2. New-member posting restrictions. No links, no forwards, no media, no @mentions for the first 24 hours or first 5 messages. Scammers who pass the CAPTCHA still need to deliver a payload — this strips their delivery mechanism while they're still suspect.
3. Drainer / phishing URL blocklist. Every posted URL checked against Scam Sniffer + PhishDestroy feeds (240k+ domains). Catches Inferno, Angel, Pink, Solana, MS, Venom drainer infrastructure. The blocklist runs parent-domain matching so daily subdomain rotation doesn't bypass it.
4. Seed phrase / private key regex detection. Auto-ban anyone posting "12-word", "seed phrase", "recovery phrase", "mnemonic", or 64-char hex strings. Zero legitimate use case in a community chat. Tolerate zero false-positive concern.
5. Wallet-drainer signature pattern detection. Auto-ban references to eth_signTypedData_v4, setApprovalForAll, permit2, ERC-20 approve() selectors. These appear in instructional scam scripts ("just sign this, takes 2 seconds") and nowhere else.
6. Admin / founder username impersonation detection. Fuzzy-match every new member's username against a whitelist of real admins. Strip zero-width chars, apply confusable map (rn→m, 0→o, l→I, 5→s), check Levenshtein distance ≤2. Ripple flagged 50+ fake Schwartz/Garlinghouse accounts on Telegram in Q1 2026 alone — this catches them at join.
7. DM warning on join. Bot greets every new member with: "Admins will NEVER DM you first. Anyone DMing you is a scammer — forward to @your_report_bot." This is preventative, not detective. It's the single best defence against pig-butchering DMs because the bot can't see DMs but the member now knows the rule.
8. Profile bio + display name scanning. Most spam accounts hide the bait in their bio, not in messages. Scan bio on join for wallet addresses, "DM for signals", "trader", Telegram handles of known scam channels. Ban on hit, no waiting for them to post.
9. Forwarded-message restrictions. Block forwards from any channel not on the allowlist, or block all forwards from new members entirely. Scammers leverage social proof by forwarding from their own fake "alpha" channels — kill that channel.
10. Coordinated-join (sybil) detection. Track join rate per minute per group. 20 accounts in 60 seconds with no overlap to existing members = swarm. Auto-mute the wave, alert admins, hold for review. This is how pump-and-dump groups inflate apparent membership and how scammers seed groups before the operator posts.

Worth adding past 10:
11. Slow mode + per-user cooldown. Telegram's built-in slow mode is blunt; a bot can apply tiered cooldowns (new members get 60s, established members get none). Massively reduces flood attacks.
12. Account-age gate. Reject any new join from an account < 7 days old. The vast majority of disposable scam accounts are < 48 hours old when deployed.
13. Image OCR for scam graphics. Scammers post screenshots ("My profits this week!" / "Contact this trader") specifically to evade text-based filters. Run Tesseract on every image and feed the extracted text back through the same rules.
14. Report button + community flagging. Inline keyboard on every bot message: "Report this user". Three reports from established members = auto-mute pending admin review. Leverages your community as a sensor network.
15. Cross-group threat propagation. If you run multiple groups (More Than Fitness, Shen Academy, Yakkafy, AussieBoomer), a ban in one propagates to all. Scammers test in one group, hit the others. Shared blocklist kills that pattern.
16. Mass-mention / copypasta detection. 5+ @mentions in one message, or identical text posted across multiple groups within minutes. Classic engagement-bait spam pattern.
17. Audit log + admin dashboard. Every action logged with reason, payload, sender. Review weekly to tune rules and catch false positives. Without this, you'll over-ban and lose real members without knowing why.
18. Behavioural anomaly scoring. Once you have a few thousand confirmed scam events, a small classifier on message length, link count, time-since-join, mention count, emoji density, and hour-of-day catches scams the regex misses. This is the v3 upgrade — start with rules, graduate to learning once you have data.
The first six alone (CAPTCHA, restrictions, blocklist, seed regex, signature regex, impersonation) handle 95% of attacks. Everything past that is closing the long tail.
