3) Anti-gaming Logic (Stop Trust Farming)

Scammers/bots will try to “farm” points by sending harmless junk messages. These rules make that expensive and ineffective.

A) Count “meaningful messages” only

A message counts only if it passes checks like:

length ≥ 12 characters OR contains 3+ real words

not just emojis

not repeated text

not copy-pasted within a short window

Rule

If message is “low value” → counts as 0 for trust

B) Daily point caps (critical)

Even humans shouldn’t gain unlimited points in a day.

Example caps

Max trust gain per day: +3

Max trust gain per week: +12

So farming 1,000 messages gives no advantage.

C) Diversity requirement (unique ratio)

Track a rolling window of last ~50 messages and measure similarity.

If too similar → stop awarding points

Practical rule

If user repeats near-identical messages 3+ times/day → no trust gain for 48 hours

D) Conversation weighting (replies count more)

Bots don’t reply naturally.

Award points like:

Normal message: +0.1 (capped)

Reply to another user: +0.3

Meaningful question/answer pattern: +0.5 (optional heuristic)

This naturally rewards real engagement.

E) “Cooldown on suspicious bursts”

If a user suddenly posts:

10 messages in 60 seconds
→ treat as bot-like and award 0 trust that day (or apply slow mode)

F) Link + trust penalty (even if allowed)

Even trusted users shouldn’t gain points by link spamming.

Rules:

Links never add trust points

If links are removed/flagged → trust score drops

Suspicious link attempt → immediate trust freeze

G) Trust freezes and decay (powerful)

If user gets flagged:

Freeze trust gains for 7 days

Optionally decay score slowly if continued suspicious behavior

Example:

+0 trust while frozen

-5 trust if another strike occurs

H) Manual override stays king

Owner command instantly changes state:

/trust @user reason (grant)

/untrust @user reason (revoke)

/trustfreeze @user 7d reason (stops farming immediately)

Recommended “Anti-gaming” settings (good defaults)

Meaningful message minimum: 12 chars / 3 words

Max trust per day: +3

Max trust per week: +12

Repetition detection window: last 50 messages

Similarity threshold: high similarity = no points

Burst limit: >10 msgs/min = no points + cooldown

Any strike: freeze gains 7 days

Any suspicious link deletion: no points for 7 days
